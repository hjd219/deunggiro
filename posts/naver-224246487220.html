법인 이사 선임 vs 감사 선임 차이 의결권제한 3% 기준 정리

법인 이사 선임 vs 감사 선임 차이 의결권제한 3% 기준 정리｜절차·필요서류·주의사항

“대주주가 지분 많으면 감사도 마음대로 선임할 수 있나요?”

“이사 선임이랑 감사 선임은 왜 다르게 보나요?”

결론부터 보면

감사 선임은 일반 이사 선임과 달리 상법상 ‘3% 의결권 제한’이 적용되기 때문에, 대주주라도 단독으로 결정하기 어려운 구조입니다.

핵심 기준은

‘감사 선임 시 의결권 제한 규정 적용 여부’입니다.

핵심 3가지

① 감사 선임 시 대주주 의결권 3% 제한 적용

② 이사 선임과 의결 구조 자체가 다름

③ 지분율이 높아도 단독 선임 불가능 가능성 존재

특히 많은 회사들이

“주식을 많이 가지고 있으면 감사도 당연히 선임 가능하다”라고 생각하지만, 실제로는 감사 독립성을 위해 별도의 제한 규정이 적용됩니다.

오늘은 감사 선임 시 대주주 의결권 제한 구조를 실무 기준으로 쉽게 정리해드립니다

1️⃣ 이사 선임 구조

이사 선임은 일반적인 보통결의 방식으로 진행됩니다.

기본 요건

출석 주주의 의결권 과반수 찬성

발행주식총수 4분의 1 이상 출석

대주주가 충분한 지분을 보유한 경우

단독 선임도 가능합니다.

2️⃣ 감사 선임 구조는 왜 다를까?

감사는 대표이사·이사의 업무를 감시하는 기관입니다.

경영진 견제 역할

회계·업무 감사 역할

그래서 상법에서는

감사의 독립성을 위해 특별 규정을 둡니다.

3️⃣ 감사 선임 시 핵심 규정

바로 이것입니다

“의결권 3% 제한”

즉 한 주주는

발행주식총수의 3%까지만 의결권 인정됩니다.

지분이 아무리 많아도

감사 선임에서는 제한 적용 가능

4️⃣ 실제 예시

예를 들어

발행주식 총수 : 10,000주

A주주 : 9,000주

B주주 : 200주

C주주 : 300주

D주주 : 300주

E주주 : 200주

5️⃣ 감사 선임 시 인정 의결권

감사 선임에서는 아래처럼 계산됩니다.

A주주 → 300주만 인정

B주주 → 200주 인정

C주주 → 300주 인정

D주주 → 300주 인정

E주주 → 200주 인정

총 인정 의결권 : 1,300주

즉 A주주는 실제 9,000주를 보유해도

감사 선임에서는 300주만 인정됩니다.

6️⃣ 왜 중요한 문제일까?

이 규정 때문에

대주주 단독 감사 선임 제한 가능

다른 주주 협조 필요

의결 계산 실수 시 결의 문제 발생 가능

특히 주주총회 의사록 작성 시

의결권 계산을 잘못하면

등기 보정 또는 반려가 발생할 수 있습니다.

7️⃣ 이사 선임과 비교하면?

이사 선임

→ 대주주 단독 가능 사례 많음

감사 선임

→ 의결권 제한 적용 가능

→ 단독 결정 어려운 구조

이사와 감사는 선임 구조 자체가 완전히 다릅니다.

8️⃣ 핵심 정리

감사 선임 시 의결권 3% 제한 가능

대주주라도 단독 선임 어려울 수 있음

이사 선임과 의결 구조 다름

의결권 계산 오류 시 등기 문제 가능
