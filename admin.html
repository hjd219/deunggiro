홈페이지
GitHub 토큰을 소스코드에 넣지 않습니다. 게시할 때 입력한 토큰은 기본적으로 저장하지 않으며, GitHub 저장소의 Contents 권한이 있는 토큰만 사용하세요.

1. GitHub 연결

권장 권한: 해당 저장소만 선택 → Repository permissions → Contents: Read and write. 토큰은 GitHub에서 직접 발급합니다.

2. 글 정보

새 글은 제목·분야를 기준으로 자동 생성되며, 기존 글 수정 시 주소는 그대로 유지됩니다.

3. 본문 작성

썸네일을 선택하면 여기에 표시됩니다.

목록·검색 공유용 대표 이미지입니다. 업로드한 이미지는 게시 시 글 HTML에 내장됩니다.

여기에 글을 작성하세요.

일반 블로그처럼 텍스트·문단·미디어·꾸미기·편집 메뉴를 사용하세요. 이미지·동영상은 삽입 후 직접 드래그해 크기를 바꾸고 × 또는 Delete/Backspace로 삭제할 수 있습니다.

본문은 HTML로 정리되어 개별 정적 페이지로 생성됩니다. 검색엔진이 읽을 수 있는 실제 HTML 파일입니다.
