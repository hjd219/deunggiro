GitHub 토큰을 소스코드에 넣지 않습니다. 게시할 때 입력한 토큰은 기본적으로 저장하지 않으며, GitHub 저장소의 Contents 권한이 있는 토큰만 사용하세요.

1. GitHub 연결

권장 권한: 해당 저장소만 선택 → Repository permissions → Contents: Read and write. 토큰은 GitHub에서 직접 발급합니다.
